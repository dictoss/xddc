Cross Distro Developers Camp

2026-08-23

もくもく会を開催しました

ディストリビューション開発もくもく会 2026 年 8 月 を開催しました。 会場は東京の幡ヶ谷にある 株式会社創夢 様の会議室とオンラインのビデオ会議でハイブリッド開催し、参加者は 8 名でした。

参加者は各自で以下の作業を行い、参加者同士で意見交換をしました。

  • ODC2026 の XDDC セミナーのスライド作成 (openSUSE, Ubuntu, Debian)
  • openSUSE 16.0, 16.1 で発生中の mozc 不具合の対応方法検討
  • Debian experimental の uim-mozc 状況確認
  • DebConf27 Web サイトの開発環境を構築する手順を作成
  • DebConf27 Web サイトの開発環境構築・修正内容検討
  • IT イベント発表の CfP 作成・レビュー
  • RISC-V ボード (BitBrick K1) Debian13 イメージの動作確認、外付 USB Bluetooth アダプタを動作させるための作業
  • RISC-V ボード (BitBrick K1) で LibreOffice 開発版のローカルビルドの手順整理(Debian 13 で Clang)
  • LibreOffice 27.2 搭載予定の LAMBDA 関数関連の動作確認
  • ODC2026 の LT 資料作成 (XDDC 紹介)
  • Yuino の学習仕込み
  • ibus-yuino を開発するための検討
  • GNU coreutils 翻訳改善のために help2man 解析

次回開催は、2026/09/19(土) 11:00-13:00 の予定です。

その後は14時から開催する、小江戸らぐ 9月のオフな集まり(第290回) に合流予定です (Software Freedom Day のイベント)。
